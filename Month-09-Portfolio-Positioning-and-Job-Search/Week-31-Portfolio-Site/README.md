## Core concepts

| Concept | In one line |
|---|---|
| **Positioning** | One sentence: who you are and the value you bring. Everything supports it. |
| **Case study** | Problem → architecture → what you built → results → mapping → lessons. |
| **Evidence-first** | Every claim links to a repo, diagram or video. No unverifiable bullets. |
| **Consistency** | One README template; a reviewer learns to read all six fast. |

## How it fits together

`Positioning` → `Case studies` → `Site build` → `Demo videos` → `Pin repos`
